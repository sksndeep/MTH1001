General Instructions & Cipher Type Descriptions

Assume \(A = 0, B = 1, \dots, Z = 25\). Wrap around after \(Z\). Preserve spaces between words where applicable.

1. Shift (Caesar) Cipher: Each letter is moved a fixed number of places. Encryption: \(E(x)=(x+k)\bmod 26\). For example, with \(k=3\), A maps to D and DOG maps to GRJ.

2. Affine Cipher: Each letter \(x\) is transformed using \(E(x)=(ax+b)\bmod 26\), where \(\gcd(a,26)=1\). Decryption uses \(D(y)=a^{-1}(y-b)\bmod 26\).

3. Vigenère Cipher: A repeating keyword supplies a different shift for each letter. For example, using key BAD with plaintext CAT gives ciphertext DAW.

4. RSA Encryption: A public-key system; encryption computes \(C=M^e\bmod n\) and decryption computes \(M=C^d\bmod n\).

5. RSA Digital Signatures: A signer creates a signature using their private key (\(S=M^d\bmod n\)) and others verify it using the public key (\(S^e\bmod n=M\)).
